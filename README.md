# BadAppleGmail
Bad Apple but in Gmail 

Rule 86 of the Internet: "If it exists, you can play Bad Apple on it. No exceptions." 

Usage: 

1. Go to Gmail 

2. Open DevTools (Ctrl Shift I / Command Option I) 

3. Paste the code from
bad-apple-mail.js (type 'allow pasting' if it prompts you) 

4. Select the Bad Apple source video attached in this repo
